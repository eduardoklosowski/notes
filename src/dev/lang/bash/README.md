## Modificadores de Variáveis

- `${parameter:−word}`: Valor padrão se não definido
- `${f%.*}"`: Nome do arquivo sem a primeira extensão
- `${f%%.*}"`: Nome do arquivo sem nenhuma extensão
- `${f#*.}"`: Extensões do arquivo
- `${f##*.}"`: Última extensão do arquivo
